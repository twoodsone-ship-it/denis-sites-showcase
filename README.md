# Сайты Дениса — витрина

Публичная страница с примерами, ценами и кнопкой «Написать в Telegram».
Хостинг: бесплатный статический сайт на Render.

Живой адрес: https://denis-sites.onrender.com

Кнопка «Написать в Telegram» ведёт на https://t.me/twoodsone

Это не агентство и не портфолио реальных заказчиков. Раздел «Работы» содержит **демо-примеры** вымышленных организаций.

## Локальный просмотр

Откройте `index.html` в браузере или запустите:

```bash
python3 -m http.server 8766
```

и зайдите на http://127.0.0.1:8766/
