# Сайты Дениса — витрина

Публичная страница с примерами, ценами и кнопкой «Написать в Telegram».
Хостинг: бесплатный статический сайт на Render.

Это не агентство и не портфолио реальных заказчиков. Раздел «Работы» содержит **демо-примеры** вымышленных организаций.

## Как подключить Telegram

1. Откройте файл `config.js`.
2. Вставьте свой ник **без знака @**:

```js
window.TELEGRAM_USERNAME = "ваш_ник";
```

3. Сохраните файл и отправьте изменения в этот репозиторий — сайт обновится сам.

Пока ник не указан, кнопка на сайте никуда не ведёт. Свой ник нигде в открытом виде в репозиторий не попал: в профиле приложения его не было.

## Локальный просмотр

Откройте `index.html` в браузере или запустите:

```bash
python3 -m http.server 8766
```

и зайдите на http://127.0.0.1:8766/

Подсказка про незаполненный ник показывается только с адресом `?admin=1`.
